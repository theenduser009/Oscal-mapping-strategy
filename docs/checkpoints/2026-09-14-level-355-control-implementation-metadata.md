# Archer Level 355 — Control Implementation metadata checkpoint

Date: 2026-09-14
Branch: `simplify-metadata-boundary`

## Why this matters

During SSP Control Implementation discovery, `ARCHER_CONTENT_AUTHORIZATION_PACKAGE_RAW.CURATED_JSON:ALLOCATED_CONTROLS` was read back as an array of Archer reference objects with the shape:

```json
{
  "ContentId": <referenced content id>,
  "LevelId": 355
}
```

Follow-up SQL against `ARCHER_META_FIELD` for `LEVEL_ID = 355` returned **210 rows** in Snowflake. The visible field names are strongly control-oriented, including `CONTROL_NAME`, `CONTROL_NUMBER`, `IMPLEMENTATION_DETAILS`, `OVERALL_IMPLEMENTATION_DETAILS`, `IMPLEMENTATION_STATUS`, `CONTROL_PARAMETERS`, `RESPONSIBLE_ROLE`, `CONTROL_ENTITY`, `CONTROL_SET`, and multiple inheritance fields.

This makes Level 355 the strongest current candidate for the Archer control-record level that may feed OSCAL SSP:

`system-security-plan.control-implementation.implemented-requirements[]`

This is a **read-back verified discovery checkpoint**, not yet an implemented mapping and not yet proof of the final OSCAL path for every Level 355 field.

## Authoritative query to rerun

```sql
SELECT
    LEVEL_ID,
    FIELD_ID,
    SQL_FIELD_NAME
FROM RTX_RAW_DEV.ES_ESC_GRC.ARCHER_META_FIELD
WHERE LEVEL_ID = 355
ORDER BY FIELD_ID;
```

## What this checkpoint does and does not prove

Confirmed from owner-provided Snowflake read-back on 2026-09-14:

- `ALLOCATED_CONTROLS` on Authorization Package contains `{ContentId, LevelId}` reference objects.
- The observed referenced `LevelId` is `355`.
- `ARCHER_META_FIELD` returned 210 fields for `LEVEL_ID = 355`.
- Many visible Level 355 fields are directly relevant to control identity, implementation, inheritance, responsibility, assessment, and control-set semantics.

Not yet confirmed:

- The physical RAW table that stores the referenced Level 355 `ContentId` records.
- Which Level 355 fields become OSCAL `implemented-requirements[]` versus child statements, by-components, props, responsible roles, parameters, or assessment-only data.
- Any target DML or registry update for this branch.
